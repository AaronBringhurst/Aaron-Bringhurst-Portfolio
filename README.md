# Aaron Bringhurst — Developer Portfolio

A personal web portfolio built with **React**, **Vite**, and **Tailwind CSS** to introduce my background and software projects.

## About

I'm a University of Utah Full Stack Web Development Boot Camp graduate developing web and mobile applications. My current independent project is **[Trek Pets](https://trek-pets.com)**, an Android walking and virtual-pet application that has completed closed beta testing.

## Technologies

- React and JavaScript
- Vite
- Tailwind CSS

## Local development

```bash
npm install
npm run dev
```

To build:

```bash
npm run build
```
